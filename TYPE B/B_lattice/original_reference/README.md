# Original reference files (unchanged)

These are the files you shared at the start: your original CadQuery script
and the four STEP parts it exported. They are kept exactly as received, so
the corrected designs in `../` can be compared against them.

**Don't print from these.** They contain the errors listed in
[`../README.md`](../README.md#errors-corrected). In short:

* The phalanx sockets cut away the whole end of each phalanx.
* The nubs, bosses and fingertip recess are on the dorsal side.
* The nubs float as separate solids.
* The pin holes don't line up between tab and socket.
* The tendon channel jumps at every joint.
* The flange screw holes are blocked.

The script here imports `ocp_vscode` for its viewer. It runs as it is if you
have that installed.
